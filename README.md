# DawnGrid

> A modern, blazing-fast native desktop spreadsheet powered by Tauri v2, Rust xlsx-engine, and Univer.

## Features

- ⚡ **High Performance**: Native Rust XLSX parsing & streaming engine with sub-second loading.
- 🎨 **Modern Ribbon UI**: Full Excel parity with pixel-perfect modern styling, full system font support, and responsive overflow controls.
- 📑 **Multi-Sheet Management**: Background pre-fetching, instant tab switching, and auto-clamped range streaming.
- 🤖 **AI Assistant**: Smart data validation, natural language spreadsheet formulas, and automated analysis.

## Development

```bash
# Install dependencies
npm install

# Run desktop dev environment
npm run tauri dev
```
